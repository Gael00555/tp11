# Installation

## Stable release

To install tp11, run this command in your terminal:

```sh
uv add tp11
```

Or if you prefer to use `pip`:

```sh
pip install tp11
```

## From source

The source files for tp11 can be downloaded from the [Github repo](https://github.com/Gael00555/tp11).

You can either clone the public repository:

```sh
git clone https://github.com/Gael00555/tp11
```

Or download the [tarball](https://github.com/Gael00555/tp11/tarball/main):

```sh
curl -OJL https://github.com/Gael00555/tp11/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd tp11
uv sync
```
