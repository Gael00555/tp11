# Changelog

Todos los cambios relevantes de este proyecto se registran en este archivo.

El formato sigue [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/).
Este archivo es el registro principal del proyecto. La carpeta `CHANGELOG/`
pertenece al flujo de release del template (`scripts/release.py`) y no debe
modificarse ni eliminarse.

## [Unreleased]

### Added

- Esqueleto inicial del proyecto generado con CookieCutter
  (`audreyfeldroy/cookiecutter-pypackage`): paquete `src/tp11`, tests con
  pytest, workflows de GitHub Actions, `justfile`, documentación y licencia MIT.
- `CONTEXT.md` con el registro de herramientas de IA y prompts utilizados.

### Changed

- `README.md` reescrito para describir el conversor JSON a CSV: características,
  instalación, uso, ejemplos, códigos de salida y desarrollo.

### Removed

- Del `README.md` original: insignias y comandos de PyPI que no aplican porque
  el paquete no está publicado.
